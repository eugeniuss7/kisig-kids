# 🌿 Kisig Kids — Official Website

> **Learning by doing. Moving by design.**  
> Official web repository for Kisig Kids, an Inclusive Learning Center located in San Juan City, Metro Manila.
>
> 📌 About Kisig Kids
Kisig Kids is an inclusive learning center providing play-based, neuro-affirming early childhood and special needs education (SNED). Grounded in Reggio- and Waldorf-inspired philosophies, Kisig Kids integrates sensory processing, cognitive milestones, reading, writing, and math into real-world action—incorporating movement, nature, and practical life skills while remaining aligned with the MATATAG curriculum framework.

🚀 Website Objectives
This repository contains the source code for the Kisig Kids web portal, designed to:

Highlight Educational Programs: Detail early childhood playclasses, special education sessions, and sensory processing activities.

Parent & Family Portal: Provide information on enrollment, program schedules, and FAQs.

Center Announcements: Share updates on sessions, literacy events, and center activities.

Contact & Admissions: Offer direct communication channels for consultations and school visits.

🛠️ Key Website Features
🎨 Program Overview: Dedicated sections for play-based learning, sensory integration, and 1-on-1 SNED programs.

📍 Location & Schedule: Interactive map and operational hours (17 Alfonso XIII St., Brgy. Pasadeña, San Juan City).

💬 Inquiry & Application Form: Streamlined inquiry submission for prospective parents and applicants.

📱 Fully Responsive & Accessible: Optimized for mobile viewing, fast loading, and neuro-inclusive UI design.

💻 Tech Stack (Suggested)
Frontend: Next.js / React (TypeScript)

Styling: Tailwind CSS (Soft, nature-inspired palette)

Hosting / Deployment: Vercel / GitHub Pages

Forms / Backend: Formspree / EmailJS
